# Samuel Trabalho Final

## Sobre o projeto

Este projeto foi desenvolvido como trabalho final da unidade curricular de Versionamento e Colaboração.

O objetivo é aplicar na prática os conhecimentos de Git e GitHub, utilizando commits, branches, merge, resolução de conflitos e versionamento.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Funcionalidades

- Página desenvolvida com HTML
- Estilização com CSS
- Funcionalidades utilizando JavaScript

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador.
